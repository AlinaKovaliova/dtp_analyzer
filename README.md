# 🚗 DTP Analyzer

## Описание проекта
Интерактивное веб-приложение для анализа данных о ДТП с использованием машинного обучения и визуализации. Проект предоставляет широкие возможности для исследования пространственных, временных и причинных закономерностей аварий.

## 🔑 Основные возможности
- **Интерактивная карта** с отображением всех ДТП
- **Кластеризация** методами KMeans, Agglomerative, BIRCH и Gaussian Mixture
- Временные тренды по годам, месяцам, дням и часам
- Анализ причин и типов травм
- Фильтрация по выходным/рабочим дням
- Межкластерный анализ факторов и травм
- Поддержка детальных отчетов по отдельным кластерам

## 📊 Технологии
- **FastAPI** — для создания API
- **Plotly** — интерактивные визуализации
- **Scikit-learn** — алгоритмы кластеризации
- **Pandas** — обработка данных
- **Jinja2** — шаблонизатор HTML

## 🚀 Установка и запуск
```bash
# Установите зависимости
pip install -r requirements.txt

# Запустите приложение
python3 -m main
```

### Главная страница
- Интерактивная карта с цветовой маркировкой типов столкновений
- Графики по времени (годы, месяцы, дни, часы)
- Топ-10 причин ДТП
- Диаграммы распределения травм и выходных дней
- Визуализации кластеров на карте

### Страница кластерного анализа
- Сравнение факторов и травм по кластерам
- Анализ сезонности ДТП
- Выбор метода кластеризации (KMeans, Agglo, BIRCH, Gaussian)
- Фильтрация по году и номеру кластера

## 🧪 Примеры использования
1. **Идентификация "горячих точек"** на карте через кластерный анализ
2. **Выявление закономерностей** травм в разных районах города
3. **Сравнение временных паттернов** ДТП по выходным и будням
4. **Анализ причин аварий** в зависимости от времени суток

## 📈 Алгоритмы кластеризации
- **K-Means**: Быстрая группировка по географическим координатам
- **Agglomerative Clustering**: Иерархический подход к анализу
- **BIRCH**: Эффективен для больших наборов данных
- **Gaussian Mixture**: Вероятностная модель кластеризации
